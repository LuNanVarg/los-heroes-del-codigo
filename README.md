## Descripción del Proyecto
Sitio web concebido bajo una identidad visual de periódico editorial retro ("La Gaceta"), implementando portada, perfiles individuales, bitácora de desarrollo y maquetación responsive sin librerías externas.

## Tecnologías Utilizadas
* HTML5 semántico
* CSS3 (Grid, Flexbox, Media Queries en 400px, 900px y 1200px)
* JavaScript ES6 nativo

## Guía de Estilos
* **Tipografías:** `Anton SC` (Títulos) y `Vollkorn` (Cuerpo de texto).
* **Paleta Cromática:**
  * Oscuro / Texto: `#242424`
  * Papel / Fondo: `#EAD9C9`
  * Acento / Borde: `#C3937C`
  * Botón Hover: `#C01C1C`

## Interacciones JavaScript
* **Portada:** Desplazamiento interactivo horizontal para el catálogo de integrantes y validación/envío dinámico del formulario de contacto.
* **Perfiles:** Generador de citas dinámico en cada tarjeta biográfica.

## Declaración sobre Uso de IA
* **Herramienta y Modelo:** Gemini (Plan Gratuito).
* **Uso:** Asistencia técnica en estructuración inicial de código semántico y verificación de breakpoints responsive.
* **Criterio propio:** El equipo revisó, adaptó y aplicó los estilos finales en Figma, integrando el contenido real y validando el funcionamiento en el navegador antes del commit final.
